# telegram_bot_collection

Monorepo с несколькими Telegram-ботами на Python, спроектированный как набор независимых мини-сервисов.

Проект используется как портфолио и демонстрирует:

- проектирование архитектуры ботов
- асинхронный Python
- работу с внешними API
- работу с базами данных через SQLAlchemy ORM
- кэширование и хранение данных
- Docker и деплой

## 📁 Структура репозитория

```
telegram_bot_collection/
│
├── bots/
│   ├── expense_tracker_bot/    # Бот для учёта расходов
│   └── yesno_bot/              # Бот с ответами да/нет и GIF
└── README.md
```

Каждый бот:

- является независимым мини-продуктом
- имеет собственную архитектуру
- может быть вынесен в отдельный репозиторий

## Боты

### expense_tracker_bot

Телеграм-бот для учёта личных расходов. Позволяет сохранять траты по категориям и хранит данные в SQLite через
SQLAlchemy ORM.

### yesno_bot

Телеграм-бот, который отвечает на вопросы случайным "Да" или "Нет" и отправляет тематическую GIF-анимацию.

## Архитектурные принципы

- многоуровневая архитектура (handlers → services → utils)
- Конфигурация через `.env`
- Асинхронный I/O (aiohttp, aiofiles)
- Работа с БД через SQLAlchemy ORM
- Чёткое разделение логики и инфраструктуры

## Docker & Deployment

Каждый бот запускается в отдельном контейнере через Docker Compose.  
Для хранения данных используются volumes (кэш, SQLite-базы данных и другие данные ботов).

## Автор

Проект создан для демонстрации навыков Python backend разработки и архитектуры Telegram-ботов.
