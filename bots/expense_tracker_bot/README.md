# Expense Tracker Bot

Telegram-бот для учёта личных расходов.

Проект разработан на **aiogram 3** и использует **SQLAlchemy ORM** для хранения данных в **SQLite**.

## Возможности

* Добавление расходов через пошаговый диалог
* Сохранение суммы, места и категории покупки
* Автоподсказки категорий на основе ранее введённых данных
* Просмотр последних расходов
* Хранение данных пользователя в базе данных

## Цель проекта

Проект начинался как практическое упражнение для изучения разработки Telegram-ботов на aiogram 3 и работы с SQLAlchemy ORM.

В дальнейшем бот стал использоваться для личного учёта расходов в повседневной жизни, поэтому развитие проекта ориентировано не только на изучение технологий, но и на решение реальной пользовательской задачи.

### В проекте отрабатываются:

* FSM в aiogram 3
* SQLAlchemy ORM
* многоуровневая архитектура
* Docker
* асинхронный Python
